RANDWRITER / PATTERNS INTO LANGUAGE
source text
k-gram modelobserve · count · sample
new sequences
A small window into probabilistic language modeling.
Probabilistic modeling · C++

RandWriter

Learning patterns. Generating possibilities.

A Markov-chain text generator that learns character transitions from source text and uses weighted sampling to produce new sequences.

C++20Markov chainsBoost.Test
Inside the project

Builds an order-k model from observed k-gram frequencies. Circular text wrapping avoids dead-end states, while weighted random selection drives generation. Includes automated tests and an additional word-based generator.

Mathematics · Interactive graphics

PTreeFractal

Seeing recursion take shape.

An interactive Pythagorean tree that turns recursive algorithms, rotations, and trigonometry into a visual exploration of fractal geometry.

C++20SFMLRecursion
Inside the project

Recursively attaches two child squares to each parent using sine and cosine scaling. Keyboard controls adjust recursion depth and branch angles, revealing how small parameter changes transform the pattern.
