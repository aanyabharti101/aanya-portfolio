# Aanya Bharti: Personal Portfolio 🙌

This is the complete local copy of your portfolio, including the latest introduction, NASTT scholar label, research entries, conference section, and community logos.

## Run it locally

1. Extract the ZIP.
2. Open Terminal in the extracted `Aanya_Portfolio` folder.
3. Run:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

4. Open http://localhost:8000 in your browser.
5. Press Control+C in Terminal to stop the server.

You need Python 3 installed for this command. Alternatively, open this folder in VS Code and use Live Server.

For a quick preview, you can also double-click `index.html`. Serving it on localhost is recommended for browser features such as Copy Email.

## Edit the website

- `index.html`: all text, layout, styling (inside `<style>`), and interactions (inside `<script>`).
- `assets/`: project screenshots and organization logos.

Save your changes, then refresh your browser. Keep `index.html` and the `assets` folder together.


Google Fonts loads the two web fonts when you are online. If you are offline, the site uses fallback fonts; included logos and screenshots remain available. Email, GitHub, LinkedIn, and external demo links open their normal destinations.

Edits to this local copy do not automatically update the hosted portfolio.
